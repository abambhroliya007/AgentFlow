# AgentFlow

AgentFlow is a lightweight multi-agent AI task runner built with Python, LangGraph, and the OpenAI API.

## Overview

This project demonstrates how specialized AI agents can collaborate to complete complex tasks through a structured workflow.

The system includes four agents:

- Planner Agent
- Researcher Agent
- Executor Agent
- Validator Agent

## Workflow

```text
User Task → Planner → Researcher → Executor → Validator
